# Sơ Đồ Ca Sử Dụng (Use Case Diagram)

Các tác nhân chính:
1. **Độc giả / Sinh viên**: Xem sách, quét QR đọc câu chuyện, gửi lưu bút tri ân, theo dõi tiến độ quỹ.
2. **Quản trị viên (Nhóm dự án)**: Đăng nhập PIN, cập nhật sách đã bán, thêm sách mới, in mã QR bookmark.
3. **Đơn vị thụ hưởng**: Trung tâm Điều dưỡng Thương binh và Người có công Long Đất.
