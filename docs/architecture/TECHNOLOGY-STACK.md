# Ngăn Xếp Công Nghệ (Technology Stack)

## 1. Frontend
- **Framework**: React 18 (TypeScript)
- **Công cụ đóng gói (Bundler)**: Vite 6
- **CSS Utility**: Tailwind CSS 3
- **Biểu tượng (Icons)**: Lucide React
- **Lưu trữ dữ liệu**: Web LocalStorage (Offline-first, không yêu cầu thiết lập máy chủ phức tạp)

## 2. Lưu trữ & Quản lý Dữ liệu
- **Database Script**: SQL ANSI / PostgreSQL / SQLite tương thích (`database/schema.sql`)
- **Tập dữ liệu mẫu**: 10 đầu sách kinh điển 1970–2000 (`database/sample-data.sql`)

## 3. DevOps & Triển khai
- **Vật chứa (Container)**: Docker, Docker Compose
- **Tự động hóa (CI)**: GitHub Actions
