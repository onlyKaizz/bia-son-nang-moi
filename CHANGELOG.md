# Changelog
All notable changes to the **Bìa Sờn Nắng Mới** project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-06
### Added
- Complete project baseline conforming to FPT University SSG105 course standards.
- Documentation baseline: PRD, SRS, ARCHITECTURE, ERD Data Dictionary, API Spec, ADRs, Research Notes.
- Database DDL schema, verified sample dataset with 10 classic wartime books, financial and inventory queries.
- Web Application in `app/biason-frontend` (React + TypeScript + Tailwind CSS).
- Interactive features: Real-time Long Đất charity campaign progress, Bookmark QR code preview, Nostalgic book details, Guestbook.
- Admin PIN dashboard (`1975`) for inventory and fund reconciliation.
