# Phân hệ Ứng dụng (App) - Bìa Sờn Nắng Mới

Thư mục này chứa các thành phần phần mềm của dự án:

## Cấu trúc:
- `biason-frontend/`: Ứng dụng web Single Page Application xây dựng bằng React 18, TypeScript, Tailwind CSS, và Vite.
  - Cổng mặc định: `http://localhost:3000`
  - Khởi chạy dev: `cd biason-frontend && npm run dev`
  - Đóng gói kiểm tra: `npm run build`
